# Support

Herdr Multiverse is pre-1.0 and under active rewrite from a Python reference
implementation to Rust. Here's where to get help.

## Questions and usage help

- Search [existing issues](https://github.com/BamBam4275/herdr-multiverse/issues)
  first — your question may already be answered.
- If this repository has
  [Discussions](https://github.com/BamBam4275/herdr-multiverse/discussions)
  enabled, ask there for general usage questions.
- Otherwise, open an issue using the
  [feature request](.github/ISSUE_TEMPLATE/feature_request.yml) or
  [bug report](.github/ISSUE_TEMPLATE/bug_report.yml) template, whichever
  fits.

## Bug reports

Use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.yml). Include
your Herdr version, the plugin version or commit, your OS and architecture,
how you installed the plugin, the exact action or pane involved, and
redacted logs.

## Security issues

Do not open a public issue for a security vulnerability. Follow the process
in [`SECURITY.md`](SECURITY.md) instead.

## Contributing

See [`CONTRIBUTING.md`](CONTRIBUTING.md) for how to build, test, and submit
changes.

## Project status

This project is a from-scratch Rust rewrite and has not reached a `1.0.0`
release. Expect breaking changes between pre-1.0 releases. See
[`CHANGELOG.md`](CHANGELOG.md) for what has shipped so far.
